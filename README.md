# Sabr Plan Co.

A responsive first-pass website for wedding coordination and planning in New Jersey, New York, and beyond.

## Preview locally

Open `index.html` in a browser. The site uses plain HTML, CSS, and JavaScript, so no build step or package installation is needed.

## Before publishing

- The website palette is inspired by the supplied Sabr Plan Co. logo: espresso brown, ivory, and warm champagne. The original is preserved in `assets/sabr-plan-co-logo.png`, and the exact script lettering is isolated for use on the site in `assets/sabr-script.png`.
- The portfolio section includes sample couple tabs and clearly marked photo/review placeholders. Replace them with real names, photos, and client-approved testimonials before presenting them as past work.
- Replace the starter copy and photography with approved business details and images.
- Connect the inquiry form to a preferred email address or form service. It currently provides front-end validation only and does not send submissions.
